# Pulse instruments

Four original, compact SVG illustrations for Routine, Food, Move and Insights. The fixed geometry uses the Pulse palette; only line drawing and opacity animate. They are decorative symbols, not charts of recorded health values. Actual values stay in the app’s existing progress controls and Insights chart.

The application uses inline copies from `illustrations.js` so dark/light colors and its animation preference apply consistently. Individual SVGs include a reduced-motion fallback. No external image or animation library is required.
