# Original Pulse instruments

Four original SVG instruments for Routine, Food, Move and Insights. They use the Pulse palette and the same rounded line language as the app icons. Linework, steam and decorative bars loop without moving page content. Inline versions in illustrations.js inherit the selected theme and animation preference; these standalone files respect device reduced motion. Insights artwork is decorative and does not display measured data. Artwork is original app geometry, not stock or externally fetched imagery.
